# ทะเบียนรับรอง test fixture

สเปกกำหนดให้ contributor ยืนยันว่า fixture ไม่มีข้อมูลส่วนบุคคลจริง เอกสารนี้คือ
ทะเบียนนั้น **เพิ่มได้อย่างเดียว ห้ามลบแถวเก่า**

`pnpm gate:attestation` จะ fail ถ้ามีไฟล์ใน `fixtures/` ที่ไม่มีชื่ออยู่ในตารางนี้

## วิธีสร้างข้อมูลสังเคราะห์

```ts
import { makeThaiId } from '@thai-pdpa-guard/core/test/helpers/make-thai-id'
```

เลขบัตรทุกตัวใน fixture ต้องคำนวณหลักตรวจให้ถูก มิฉะนั้น detector จะปฏิเสธและ
การทดสอบจะวัดสิ่งที่ไม่ตรงกับที่ตั้งใจ

> ตัวอย่างในเอกสารต้นทาง `3-1005-00123-45-1` **ไม่ผ่าน checksum** — หลักที่ถูกต้อง
> คือ `8` ต้องแก้ทุกที่ก่อนเอาไปใช้เป็น fixture
