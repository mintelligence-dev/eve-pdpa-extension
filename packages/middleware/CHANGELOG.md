# Changelog

## Unreleased

- New package. `pdpaExpress`, `pdpaHono` and `withPdpa` (Next.js route handlers) protect the customer's text in a JSON request body with a core guard before the handler runs, and with `responseFields` check a JSON reply on the way out. `protectRequest` / `protectResponse` do the same for any web-standard `Request`, and `protectBody` for parsed JSON from any framework. Field presets `chat` (default), `openai`, `anthropic` and `ai-sdk`. A blocked message is answered 422 with `blockedBy` unless `onBlocked` says otherwise. `createGuard`, `definePolicy`, `parsePolicy` and `PdpaError` are re-exported from core, so this package alone is enough to install. A JSON body is read even when sent as `text/plain` or with no content type; items with `role: 'system'` or `'developer'` are skipped; a request or reply with nothing to protect passes through byte for byte; `onBlocked` is told the boundary, and a blocked reply answers 502. Presets include the OpenAI Responses API's `input` and a `line` preset for LINE webhooks. `context` — the other side's last message, as a string for `protectBody` or a function (may be async, given the parsed body) for the adapters — lets a bare reply to a question like "your account number?" be found. A request body over `maxBytes` (default 1 MB) is answered 413; a reply labelled JSON that is not JSON is answered 502; a path may start with `[]` for a body that is an array; a path written twice is scanned once; `*` in a path is every key of an object, and a string two paths reach is scanned once. `onNoMatch` is called when `fields` reach no string in a body read as JSON, so a missing `fields` is noticed (`protectBody` now also returns `matched`); a body already read before the web adapters or Hono middleware is an error that says so, not a bare `unusable`. `sessionId` and `ref` are given the body read as JSON too, so a chat id sent in the body can be read on Hono and Next.js, where the request body cannot be read without `await`; a reply is checked with the same values. A misspelt preset or a bad path throws when `pdpaExpress`, `pdpaHono` or `withPdpa` is created, not on the first request. Runs on Node 18.18 and later, as core does, and ships ESM and CommonJS builds; the built package is smoke-tested on every Node major from 18.18, Deno, Bun and workerd.
