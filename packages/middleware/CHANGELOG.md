# Changelog

## Unreleased

- New package. `pdpaExpress`, `pdpaHono` and `withPdpa` (Next.js route handlers) protect the customer's text in a JSON request body with a core guard before the handler runs, and with `responseFields` check a JSON reply on the way out. `protectRequest` / `protectResponse` do the same for any web-standard `Request`, and `protectBody` for parsed JSON from any framework. Field presets `chat` (default), `openai`, `anthropic` and `ai-sdk`. A blocked message is answered 422 with `blockedBy` unless `onBlocked` says otherwise. `createGuard`, `definePolicy`, `parsePolicy` and `PdpaError` are re-exported from core, so this package alone is enough to install. A JSON body is read even when sent as `text/plain` or with no content type; items with `role: 'system'` or `'developer'` are skipped; a request or reply with nothing to protect passes through byte for byte; `onBlocked` is told the boundary, and a blocked reply answers 502. Presets include the OpenAI Responses API's `input` and a `line` preset for LINE webhooks. `context` — the other side's last message, as a string for `protectBody` or a function (may be async, given the parsed body) for the adapters — lets a bare reply to a question like "your account number?" be found.
