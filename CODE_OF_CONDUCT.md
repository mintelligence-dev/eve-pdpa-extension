# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and
not the person, and no harassment of any kind. This applies to issues, pull
requests, reviews and every other project space.

One rule is specific to this project: **never post real personal data** — not
yours, not a customer's — in an issue, a pull request or a discussion. Use
synthetic values.

## Reporting

Report unacceptable behaviour to **kunlachat@m-intelligence.tech**. Reports are
handled in confidence. Maintainers may remove comments, commits and
contributions that break this code, and may block repeat offenders.
